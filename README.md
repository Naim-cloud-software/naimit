# Naimit: Cyber Battle

Quiz + hack battle game. Host a quiz, players join with a PIN, answer questions and use hacks (Steal, Virus, Freeze, Swap, Blackout, Overclock, Firewall, Jackpot) on each other.

Live: https://naimit-ncs.web.app

Deploys automatically to Firebase Hosting (project naimit-ncs) on every push to main. Needs repo secret FIREBASE_SERVICE_ACCOUNT (service account JSON).
